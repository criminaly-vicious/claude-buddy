# 0005. Original character art, no official branding

- **Status:** Accepted
- **Date:** 2026-10-27

## Context
The buddy is inspired by the orange pixel mascot associated with Claude Code. Using official logos or artwork could infringe trademarks and imply endorsement.

## Decision
Draw an **original** character with its own silhouette and details. Do not ship Anthropic logos, the Claude starburst, or copied sprites. The README states the project is unofficial and not affiliated with Anthropic.

## Consequences
- Art is created in-repo (`assets/sprites/`) under the project license.
- If the project grows, reconsider the name and request guidance on trademark use.
